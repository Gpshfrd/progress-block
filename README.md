# Progress Block

Прототип блока Progress для мобильных веб-приложений.
Реализован на HTML, CSS и JavaScript без библиотек и фреймворков.

## Возможности

- Изменение прогресса от 0 до 100.
- Дуга начинается на позиции «12 часов» и растёт по часовой стрелке.
- Включение вращения через переключатель Animate.
- Скрытие кольца через переключатель Hide.
- Независимое управление значением, вращением и видимостью.
- Адаптация расположения элементов под ориентацию экрана.
- Проверка введённого значения.

## Запуск

Склонируйте репозиторий и откройте `index.html` в браузере.
Установка зависимостей и сборка не требуются.

## Структура проекта

- `index.html` — разметка приложения.
- `styles.css` — оформление и адаптивная сетка.
- `progress.js` — класс Progress для управления кольцом.
- `script.js` — связь элементов управления с экземпляром Progress.

## API

Класс Progress принимает SVG-элемент кольца.
Внутри него должен находиться круг с классом `ring-progress`
и атрибутом `pathLength="100"`.

```js
const ring = document.querySelector(".ring");
const progress = new Progress(ring);

progress.setValue(65);
progress.setAnimated(true);
progress.setHidden(false);
```

### setValue(value)

Устанавливает прогресс. Числовые значения ограничиваются
диапазоном от 0 до 100. Значения, которые нельзя преобразовать
в конечное число, игнорируются.

### setAnimated(animated)

Включает или выключает вращение.
Принимает логическое значение `true` или `false`.

### setHidden(hidden)

Скрывает или показывает кольцо.
Принимает логическое значение `true` или `false`.
При скрытии место кольца в макете сохраняется.

## Переиспользование

Подключите `styles.css` и `progress.js`, добавьте разметку кольца
и создайте экземпляр Progress для его SVG-элемента.

Файл `script.js` относится к демо: для управления компонентом
из другого приложения он не требуется.
